SECURITY

Conservative by design.

The project separates monitoring authority from mutation authority and keeps its security claims bounded by reproducible evidence.

Local-first

The console does not require a cloud account. The default dashboard/API binding is loopback.

Least privilege

The validated service uses a dedicated non-login syswatch account and explicit state boundaries.

Protected State

Integrity, malformed-state, bounded-resource, race and persistence regression paths are exercised.

No Destructive Default

The current policy/evidence layer is read-only and does not silently execute containment or host mutation.

Supply Chain

Release engineering includes pinned actions, dependency audit, SBOM generation, checksums and provenance ordering.

Honest Claims

Controlled tests are not presented as proof of universal malware-detection accuracy or production EDR certification.

Security status: No independent external security evaluation has been completed or claimed. Privileged response remains gated until its complete execution chain is independently validated.
