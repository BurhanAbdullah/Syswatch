FEATURES

Security context, not alert volume.

System Watch turns local host telemetry and normalized security signals into temporal, evidence-backed behavioral context for a local operator.

Endpoint intelligence

Host identity, resources, interfaces, listening endpoints, and bounded process intelligence.

Security posture

Firewall, Wi-Fi, and SSH posture where the host exposes trustworthy telemetry.

Causal correlation

Normalized signals are related across bounded temporal windows to expose behavioral chains.

Behavioral baseline

Local host context describes normal behavior and highlights meaningful deviations.

Evidence timeline

Events, severity, confidence, and chain context remain inspectable by the operator.

Local-first boundary

The dashboard is loopback-bound by default and the current policy layer is read-only.

Pre-release · Evidence-driven development
ARCHITECTURE

Observe → Correlate → Understand → Respond

Response is deliberately separated from observation and evidence. The current execution broker fails closed and has no default privileged adapter.

01 · Observe

Collect host, process, filesystem, and network telemetry within bounded local interfaces.

02 · Correlate

Normalize signals and evaluate temporal relationships without requiring a cloud control plane.

03 · Understand

Build baseline context, causal evidence, and read-only policy evidence for operator review.

04 · Respond

Privileged host mutation remains disabled until the complete authorization, execution, rollback, audit, and adversarial test chain is independently validated.

SECURITY

Conservative by design.

Local-first

The local console does not require a cloud account and the default API binding is loopback.

Least privilege

The packaged service uses a dedicated non-login account and explicit writable state boundary.

No destructive default

The current policy/evidence API does not execute containment, commands, or host mutation.

Honest scope

Controlled tests are not represented as evidence of universal real-world malware-detection accuracy.

Linux validation boundary

The currently verified release-readiness target is Ubuntu 24.04 LTS / Linux amd64; other platforms are not promoted as released support here.

Pre-release status

No published release is represented here; release links remain informational until a verified semantic-version artifact exists.
