Operator command contract

# installation / upgrade are installer operations, not service commands
sudo SYSWATCH_REF=main ./install.sh
sudo apt install ./syswatch_<version>_amd64.deb

syswatch start | stop | restart | status | health
syswatch dashboard | logs | scan | demo
syswatch signal TYPE "message"
syswatch version | doctor | uninstall

Lifecycle commands require a real systemd host. Privileged host mutation and real containment remain disabled by default.
